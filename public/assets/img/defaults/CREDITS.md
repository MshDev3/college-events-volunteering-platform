# Image credits

Default photos bundled with the portal. All are free photos from [Unsplash](https://unsplash.com) (not Unsplash+), used under the [Unsplash License](https://unsplash.com/license). Attribution is not required, but it is given here.

**Content rule:** the college is for male students, so every photo shows only men, or no people at all. Each photo was checked by eye, including backgrounds and crowds. There are also no brand logos and no text burned into the images.

**Format:** every photo is centre-cropped to 16:9, 1600×900, JPEG under 250 KB.

**Selection:** these are **defaults only**. An image an admin uploads (event, volunteering opportunity, facility, or the About page in Settings) always takes priority. Numbered files (`workshop-1.jpg`, `workshop-2.jpg`…) are alternatives for the same type; the record id picks one (`id % count`), so neighbouring cards of the same type differ. The event type "other", and unknown types, use `general-N.jpg`. To add an alternative, drop in the next number (e.g. `lecture-3.jpg`); no code change is needed.
